# 📄 SynapseCV — AI-Powered Resume Intelligence Platform

> **AI-powered resume intelligence platform leveraging NLP semantic matching and LLM prompt pipelines to evaluate candidate profiles against ATS screening models.**

## 🌟 Overview

**SynapseCV** provides in-depth ATS evaluation, keyword gap analysis, tone/style review, and structural feedback to help job seekers maximize their interview callbacks.

- 🧠 **NLP Semantic Matching**: Analyzes context and relevance rather than just primitive keyword stuffing.
- ⚡ **Real-Time ATS Gap Analysis**: Pinpoints missing skills, qualifications, and formatting errors instantly.
- 🎯 **Actionable Optimization Suggestions**: Direct suggestions for restructuring bullet points, quantifying achievements, and enhancing impact.
- 🔒 **Privacy-First**: Client-side evaluation and secure processing with zero credential harvesting.

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, React Router
- **AI & NLP**: OpenAI API, Prompt Engineering Pipelines
- **Styling & UI**: Tailwind CSS, Lucide Icons

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/YugNanda/SynapseCV.git

# Install dependencies
npm install

# Start development server
npm run dev
```
